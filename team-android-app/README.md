# Australia Street Équipe Android

Application Android installable dédiée à l'équipe Australia Street.

- Package : `fr.nastx.australiastreet.equipe`
- Version : `1.0.0`
- Source web : `https://djnastx-a11y.github.io/POINTAGE-NASTX/team-app-next/`
- L'application personnelle `Mon Pointage` reste séparée et n'est pas modifiée.

Le shell Android ouvre uniquement le chemin de l'application équipe dans une WebView sécurisée. Les liens externes sont ouverts hors de l'application. Le sélecteur de fichiers est disponible pour le dépôt de documents et un pont natif permet l'enregistrement des exports PDF/CSV dans Téléchargements.
